# 🚀 Flutter Starter App

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Flutter Version](https://img.shields.io/badge/Flutter-3.x-blue)](https://flutter.dev)

A production-ready Flutter starter template built with **Clean Architecture**, **SOLID principles**, and **GetX** for state management, routing, and dependency injection. 

Designed specifically for **beginner Flutter developers**, this template eliminates weeks of boilerplate setup so you can focus on learning Flutter's core concepts while following industry best practices.

---

## ✨ Why Use This Starter?

- **⚡ Time-Saving**: Jump straight into building your app logic without wrestling with architecture setup.
- **🧱 Clean Architecture**: Clear separation of presentation, domain, and data layers.
- **📦 GetX Integration**: Pre-configured state management, routing, and DI to keep your code lean.
- **📐 SOLID Principles**: Codebase structured to be maintainable, scalable, and easy to understand.
- **👶 Beginner-Focused**: The code is heavily structured to teach *why* things are placed where they are.

---

## 🗺️ The Future: LEGO Architecture + bloc_signals

This project is currently evolving! Our **ultimate goal** is to become the *gold standard* Flutter starter. We are actively migrating to:

- **🧩 LEGO Architecture**: A modular, composable "brick" system where each feature is self-contained and interchangeable.
- **⚡ bloc_signals**: A high-performance state management bridge combining the BLoC pattern with reactive Signals (glitch-free, auto de-duplication).
- **📂 Monorepo Structure**: Making it easier to pick and choose which "bricks" (modules) you want in your app.

> *Check out our [ROADMAP.md](./ROADMAP.md) to see exactly how we are getting there!*
